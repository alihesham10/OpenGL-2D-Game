
# 🎮 OpenGL 2D Game

A 2D game developed using **C++ and OpenGL** as a university Computer Science and Engineering project. The game features interactive gameplay, player movement, enemy combat, and wave-based progression.

## 🕹️ Gameplay Features

- **Player Movement:** Control the player through keyboard inputs.
- **Jumping & Ducking:** Perform different movements to avoid enemies and obstacles.
- **Enemy Spawning:** Enemies spawn dynamically throughout the game.
- **Combat System:** Engage enemies using the game's combat mechanics.
- **Wave-Based Gameplay:** Progress through multiple enemy waves with increasing challenges.
- **Collision Detection:** Detect interactions between the player, enemies, and game objects.
- **Game States:** Main menu, active gameplay, victory, and defeat screens.

## 🛠️ Technologies Used

- **C++** – Core game logic and implementation.
- **OpenGL** – 2D graphics rendering.
- **GLFW** – Window management and input handling.
- **GLAD** – OpenGL function loading.
- **GLM** – Mathematical operations and transformations.
- **CMake** – Build configuration and project management.

## 🏗️ Project Structure

The project is organized into modular components to separate gameplay logic, rendering, input handling, and game management.

## 🚀 Getting Started

### Prerequisites
- C++ compiler supporting C++17 or the project's configured standard.
- CMake.
- GLFW, GLAD, and GLM dependencies.

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory.

3. Configure the project using CMake.

4. Build the project.

5. Run the generated executable.
